# HomeTV — Giao diện xem kênh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Người xem chuyển sang mode HomeTV bằng icon cạnh logo, duyệt và tìm kênh, xem kênh qua proxy của HomeFlix với stream dự phòng, điều khiển được bằng remote TV.

**Architecture:** Phần server thêm `hometv/catalog.py` (đọc sổ kênh + yêu thích/gần đây), `hometv/play.py` (token ký, viết lại playlist, mở upstream có chặn SSRF) và `hometv/public_api.py` (router công khai). Phần client thêm mode `mode-hometv` vào `index.html`; logic thuần ở `static/hometv-utils.js`, DOM ở `static/hometv.js`, player riêng dùng `<video>` riêng và chia sẻ cấu hình hls.js qua `HFPlayerUtils.hlsConfig`.

**Tech Stack:** FastAPI, httpx, sqlite3, m3u8 (đã có), hls.js, pytest + Playwright, `node --test` cho `tests/js`.

**Spec:** `docs/superpowers/specs/2026-10-31-hometv-ui-design.md`. Đọc cả spec gói 2 (`2026-10-31-hometv-iptv-ingest-design.md`) cho bảng `channels`/`streams`/`sources`.

## Global Constraints

- TDD: test trước, thấy FAIL, rồi mới viết code (CLAUDE.md). Chạy test liên quan trước mỗi commit.
- Test gọn, một người dùng (memory `lean-tests-single-user`); không gọi mạng thật: upstream giả bằng `httpx.MockTransport`, DNS giả bằng fixture `public_dns` (`tests/conftest.py`).
- Tên file test theo mẫu hiện có: `tests/hometv/test_hometv_<tên>.py`, `tests/ui/test_hometv_<tên>.py`, `tests/js/<tên>.test.mjs`.
- Chuỗi giao diện bằng tiếng Việt, comment tiếng Việt, theo giọng code hiện có.
- Chỉ phát kênh có stream `active=1`, `drm_hint=0`, thuộc nguồn `rights_status='approved'` và `enabled=1`; kênh `enabled=1`. Kiểm tra lại ở mỗi request `play`, không cache.
- URL gốc, `http_headers`, `drm_hint` không bao giờ nằm trong phản hồi JSON công khai.
- Proxy HomeTV: timeout kết nối 10 giây, đoạn tối đa 20 MB (`seg`), playlist tối đa 2 MB, tối đa 5 lần chuyển hướng, `netguard` ở mọi lần kết nối và chuyển hướng, không ghi đĩa. Lỗi upstream, chặn, sai Content-Type: `502`. Token sai: `403`. Stream không hợp lệ: `404`. Token hết hạn sau 2 giờ.
- Yêu thích/gần đây: giữ 20 kênh gần nhất; `PUT/DELETE/POST` yêu cầu `Content-Type: application/json` (`415` nếu không). `/api/hometv/*` không thêm vào `DEVICE_COOKIE_PATHS`.
- `hometv.db` không mở được: `503`, HomeFlix vẫn chạy.
- Client: ngưỡng stream hỏng 8 giây chưa có frame đầu; debounce đổi kênh 400 ms; lưới render theo lô 60; chuỗi từ API gán bằng `textContent`, không `innerHTML`; `localStorage` luôn bọc `try/catch`.
- Giao diện dùng lại `.movie-card`, `.poster-wrap`, `.movie-title`, `.movie-meta`, `.movies-grid`, `.skeleton-card`, `.filter-option`, biến màu của `static/hf.css`; không màu mới. Ô logo tỷ lệ `16 / 9`; mobile lưới 2 cột.
- Mọi file tĩnh mới phải qua `{{ asset('...') }}` và có trong `ASSETS` của `tests/test_static_versioning.py`.

### Task 4: `hometv/play.py` — token, viết lại playlist, mở upstream

**Files:**
- Create: `hometv/play.py`
- Test: `tests/hometv/test_hometv_play.py`

**Interfaces:**
- Consumes: `netguard.check_url`, `netguard.check_host` (đồng bộ, chạy trong `asyncio.to_thread`), `fetcher.FetchError`, `fetcher.make_client`.
- Produces:
  - `sign(stream_id: int, url: str, kind: str, now: float) -> str` với `kind` thuộc `"pl" | "seg" | "direct"`; trả chuỗi an toàn cho query (base64url của JSON + `.` + HMAC-SHA256 hex rút gọn 32 ký tự). Khoá: `secrets.token_bytes(32)` ở mức module.
  - `verify(token: str, stream_id: int, now: float) -> tuple[str, str] | None` trả `(url, kind)`; `None` nếu sai chữ ký, sai `stream_id`, hết hạn (2 giờ), hoặc hỏng định dạng; so sánh bằng `hmac.compare_digest`.
  - `is_direct_url(url: str) -> bool`: đuôi path (không phân biệt hoa thường) thuộc `.ts .mp4 .mkv .flv .webm .aac .mp3`.
  - `rewrite_playlist(body: bytes, base_url: str, stream_id: int, now: float) -> str`: dùng thư viện `m3u8`; master → mọi `playlists`, `iframe_playlists`, `media` có URI thành `.../seg?u=<token kind pl>`; media → `segments`, `keys`, `segment_map` thành token `seg`. Mọi URI giải theo `base_url`. URI tương đối → tuyệt đối trước khi ký. Ném `PlaylistError` nếu không bắt đầu bằng `#EXTM3U` (sau BOM/khoảng trắng đầu).
  - `class PlaylistError(ValueError)`.
  - `async def open_upstream(client, url: str, headers: dict[str, str], *, max_redirects: int = 5, timeout: float = 10.0) -> tuple[httpx.Response, str]`: gửi `stream=True`, tự theo chuyển hướng, `netguard` ở mỗi hop, trả (response đang mở, URL cuối); caller đóng `aclose()`. Lỗi → `fetcher.FetchError`.
  - `upstream_headers(http_headers: dict, range_header: str | None) -> dict[str, str]`: map `user_agent`→`User-Agent`, `referrer`→`Referer`, chuyển `Range`; không gì khác.
